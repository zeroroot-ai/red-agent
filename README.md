# red-agent

> [!IMPORTANT]
> **🔴 The owner writes this agent by hand. No Claude session builds it.**
> The full description and the contract are in [zeroroot-ai/gibson#1511](https://github.com/zeroroot-ai/gibson/issues/1511).

An ADK-built Gibson agent that proves a flaw inside the scope of its mission and submits the proof, so a fix can be verified.

It is built with the ADK (`gibson component init --kind agent`), the same way as `cve-triage`.
